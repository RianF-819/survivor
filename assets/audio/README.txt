Folder ini disiapkan untuk file BGM berformat FLAC (genre House/Electronic), contoh:
house_groove.flac

Fitur Audio:
1. Game memiliki Procedural Web Audio Synthesizer bawaan (124 BPM House Groove) yang langsung aktif dan menghasilkan musik elektronik tanpa memerlukan file eksternal.
2. Anda juga dapat meletakkan file 'house_groove.flac' di folder ini, atau mengunggah file FLAC milik Anda sendiri melalui menu Pengaturan (Audio & IEM Settings) di dalam game.
3. Seluruh audio diproses melalui Precision IEM Channel Balancer (Equal-Power law) untuk mencegah bias channel kiri pada In-Ear Monitor berkabel.
